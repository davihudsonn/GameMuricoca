# 🦟 Mata Mosquito

Um jogo desenvolvido com **HTML, CSS, JavaScript e Bootstrap**, criado como meu primeiro projeto de jogo utilizando manipulação do **DOM** e conceitos fundamentais de JavaScript.

## 🎮 Sobre o projeto

O objetivo do jogo é simples: **eliminar os mosquitos que aparecem aleatoriamente na tela antes que o tempo acabe**.

O jogador pode escolher entre diferentes níveis de dificuldade, que alteram a velocidade de aparecimento dos mosquitos.

O projeto nasceu como uma experiência prática para entender como tecnologias básicas do desenvolvimento web poderiam ser utilizadas para criar uma aplicação interativa.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- DOM (Document Object Model)

## ⚙️ Funcionalidades

- 🎯 Sistema de níveis de dificuldade
- 🦟 Mosquitos posicionados aleatoriamente na tela
- ❤️ Sistema de vidas
- ⏱️ Contagem regressiva
- 🎮 Interação através de cliques
- 🔄 Criação e remoção dinâmica de elementos
- 📱 Interface adaptada ao tamanho da tela
- 🏆 Sistema de vitória e derrota

## 🧠 Conceitos praticados

Este projeto foi desenvolvido com foco no aprendizado e prática de:

- Manipulação do DOM
- Eventos JavaScript
- Funções
- Variáveis e condicionais
- `setInterval()` e `setTimeout()`
- Geração de números aleatórios
- Manipulação de elementos HTML
- Alteração dinâmica de estilos
- Parâmetros através da URL
- Estruturação de interfaces com Bootstrap

## 🎯 Objetivo do projeto

Mais do que criar um jogo, este projeto teve como objetivo colocar em prática conceitos fundamentais de desenvolvimento web e entender como **HTML, CSS e JavaScript podem trabalhar juntos para criar uma experiência interativa**.

Foi meu primeiro jogo desenvolvido utilizando essas tecnologias e representa uma etapa importante na minha evolução como desenvolvedor.
